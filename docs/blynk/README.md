# Blynk screenshotovi

Ovdje spremi screenshotove svog Blynk dashboarda kao dokumentaciju/referencu
(Blynk ne nudi izvoz predloška u datoteku, pa je slika najbliže moguće
"backupu" koji se može commitati na GitHub):

- `web-dashboard.png` — Blynk.Console → tvoj uređaj → Web Dashboard
- `mobile-dashboard.png` — screenshot iz Blynk mobilne aplikacije
- `datastreams.png` — Blynk.Console → Templates → tvoj template → Datastreams tab
                       (tablica svih virtualnih pinova s min/max/tip)

Ove slike NE sadrže tajne podatke (auth token, WiFi lozinku) same po sebi,
ali svejedno provjeri prije uploada da slučajno u screenshotu ne bude
vidljiv Device Auth Token (Blynk.Console → Devices → tvoj uređaj → Device Info).
